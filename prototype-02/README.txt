THE F WARD — INTERACTIVE PROTOTYPE 02

PURPOSE
Compare the small white standard department hotspots with the warmer, slower-pulsing Restricted Area hotspot. Labels are hidden at rest and appear on mouse hover or keyboard focus.

INSTALL
1. Keep prototype-01 unchanged.
2. In GitHub, create a new folder prototype-02 (e.g., create prototype-02/README.md).
3. Upload the files INSIDE this ZIP's fward-prototype-02 folder into the GitHub prototype-02 folder.
4. Visit https://vyfmdykw72-sudo.github.io/hospital-assets/prototype-02/ after publishing.

TEST
- Enter Hospital; rotate the panorama to find the white and amber markers.
- Hover a marker: its department label should appear only while hovering.
- Click a marker: a placeholder department preview opens, except Exit Hospital.
- Close the preview and verify the panorama becomes sharp again.
- Use Tab to focus markers and Enter to activate; test on phone if available.

NOTES
- All hotspot positions are placeholders, NOT aligned to the final sitemap or physical doors.
- The amber marker is a navigation experiment, not a permanent design decision.
- This is a style test, not a historical reconstruction. The art direction spans the 1940s–1950s.
- Pannellum 2.5.6 is bundled locally; no CDN needed.
- Original prototype-01 remains untouched.
